# L'imaginarium du Docteur Noirpeste

Site de la salle de jeux de rôle : planning, scénarios, comptes joueurs, réservations et espace MJ.

- Page unique `index.html` (HTML, CSS et JavaScript), servie telle quelle par Vercel.
- Données et comptes : Supabase (projet `imaginarium-noirpeste`).
- Chaque envoi sur la branche `main` met le site à jour automatiquement.
